# Starry Night

A Claude Code mod that puts Van Gogh's *The Starry Night* (1889) behind the chat in the Claude desktop app, repainted in about 7,500 vector brushstrokes under frosted glass, with the app's colours taken from the painting.

## Install

At the prompt of a terminal session:

```
/plugin install starry-night --marketplace ded-furby/starry-night
```

Answer `y` to add the marketplace, then press Enter to install it for your user, so every chat gets the painting.

From a shell:

```bash
claude plugin install starry-night --marketplace ded-furby/starry-night
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `ded-furby/starry-night`, then Add plugin.

To turn it off:

```bash
claude plugin disable starry-night@local-mods
```

The painting is in the public domain.
